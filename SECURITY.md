# Security

This repository contains **documentation only**. It holds no source code,
no secrets, no credentials, and no production data.

Please **do not report vulnerabilities by opening public issues**.

## Scope

Because this repository is documentation-only:

- There is no runtime, service, or endpoint to attack in this repository.
- Security-relevant design of the actual engine (tenant isolation, certificate
  handling, snapshot immutability, audit trace) is described at a high level in
  [`docs/07-security/security-overview.md`](docs/07-security/security-overview.md).
- Deep security architecture, threat modeling, and the internal security audit
  are part of the private technical due-diligence material and are shared under
  NDA, not published here.
